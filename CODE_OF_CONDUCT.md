# Code of conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the work. Harassment, insults and personal attacks aren't welcome in issues, pull requests or anywhere else the project lives.

To report a problem, use GitHub's private vulnerability reporting on this repository (Security tab), which reaches the maintainer privately. Reports are kept confidential.
